// STEP 01 — PREPROCESSING

Cleaning the Code

Before anything else, the preprocessor runs through your source file. It replaces #include with actual file contents, expands #define macros, and strips out every comment. What comes out is a clean, expanded version of your code.

→ output: expanded .c / .cpp file
1 #include <stdio.h>
2 #define MAX 100
3 // entry point
4 int main() {
5   printf("Hello");
6   int x = MAX;
7 }
→ /* stdio.h contents: printf, scanf, FILE... */
→   int x = 100; /* MAX expanded */
// STEP 02 — COMPILATION

Code → Assembly

The compiler checks your syntax, builds a parse tree, optimizes the logic, and converts your high-level code into assembly language — low-level instructions specific to your CPU architecture.

→ output: .s (assembly file)
C source
int add(int a, int b) {
  return a + b;
}
printf("%d", add(3, 4));
GCC / Clang
x86-64 ASM
assembly output
add: ; function prologue
  push  rbp
  mov   eax, edi
  add   eax, esi
  ret
// STEP 03 — ASSEMBLY

Assembly → Binary

The assembler translates each assembly instruction into raw binary — actual 0s and 1s the CPU can read. The result is an object file, but it's not yet runnable. References to external functions are left as unresolved placeholders.

→ output: .o (object file)
mov  eax, edi
add  eax, esi
ret
↓
// STEP 04 — LINKING

Combining Everything

The linker stitches your object file together with library files (like the one containing printf). It resolves all those unresolved references and produces a single, self-contained executable.

→ output: .exe / a.out
📄 main.o

// STEP 05 — LOADING

OS Takes Over

The operating system's loader maps your executable into RAM. It sets up separate memory regions: the stack for function calls, the heap for dynamic allocations, and the code segment for your instructions.

// STEP 06 — EXECUTION

CPU Runs It

Finally, the CPU enters its infinite fetch-decode-execute cycle. It fetches the next instruction from the program counter, decodes what operation to perform, executes it — then repeats billions of times per second until your program finishes.
